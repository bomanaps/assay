    good to know
    
      
    The Merkle-Patricia rows are pure EVM computation, where the compiler's codegen decides the bill, and Fe's walk comes out 3.2x to 3.4x cheaper on the same mainnet proofs. The SSZ rows spend most of their gas in the SHA-256 precompile, which costs the same whoever calls it, so they sit near parity and belong on the board anyway.

    Run it on your machine
    
        
      
    
      
    Needs the Fe v26.6.0 release binary on your PATH (or pointed to by FE=), Foundry for anvil and cast, and Python 3. It captures at the live chain head, so every run proves a different block; nothing in the repository is modified.
    
      
    git clone https://github.com/bomanaps/assay && cd assay
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements-capture.txt
.venv/bin/python3 tools/demo_fork.py
