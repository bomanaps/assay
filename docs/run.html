Frame transactions

        

          On Ethereum's next-fork devnet, our gate verified a storage proof on chain inside a
          real transaction, and the frame transaction that would let that proof approve its own
          gas was refused by every node for exceeding the validation budget. This is the one
          section without a live button because the devnet's servers refuse connections from
          browsers. The evidence below is recorded, and the commands rerun it against the
          devnet from any terminal.
