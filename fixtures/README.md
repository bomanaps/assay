# Fixtures

Captured proofs and the headers they are proven against. Trie fixtures (kind `account` or `storage`) come from `eth_getProof`; their command reproduces the file given the same chain history. Beacon fixtures (kind `beacon_chain` or `beacon_validator`) come from `tools/capture_beacon.py`: the chain capture takes the head minus two blocks, and the validator capture needs the finalized state named in its row.

Check every fixture with `python3 -I tools/oracle_mpt.py fixtures/*.json` and `python3 -I tools/oracle_ssz.py fixtures/*.json`; each tool checks the kinds it knows and skips the rest.
