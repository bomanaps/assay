# Fixtures

Captured proofs and the headers they are proven against. Trie fixtures (kind `account` or `storage`) come from `eth_getProof`; their command reproduces the file given the same chain history. Beacon fixtures (kind `beacon_chain` or `beacon_validator`) come from `tools/capture_beacon.py`: the chain capture takes the head minus two blocks, and the validator capture needs the finalized state named in its row. `synthetic_tries` is not captured: `tools/synth_trie.py generate` builds it from a fixed seed, and `synth_trie.py check` proves the committed file is what that seed gives. `ethereum_tests/` holds five trie vector files copied unchanged from ethereum/tests commit c67e485ff8b5be9abc8ad15345ec21aa22e290d9 (`TrieTests/`, MIT, license alongside); `test_oracles.py` checks that `synth_trie.py` rebuilds every root in them, and `tools/spec_crosscheck.py` checks the synthetic roots and these vectors against the trie of ethereum/execution-specs at the commit in `tools/requirements-spec.txt`.

Check every fixture with `python3 -I tools/oracle_mpt.py fixtures/*.json` and `python3 -I tools/oracle_ssz.py fixtures/*.json`; each tool checks the kinds it knows and skips the rest.
